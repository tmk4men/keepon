# KeepOn — 止まっても戻れる

「トレーニングをやめない」ためのAI復帰支援アプリ。
完璧に続けるのではなく、**止まっても戻れる**状態を作ることに特化しています。

## コンセプト

- **「ゼロ」を作らない** — 1分のストレッチでも「継続成功」として扱う
- **止まったら軽くする** — 数日空くと、メニューが自動で軽量化／復帰モードに切り替わる
- **連続記録ではなく「戻る力」** — 復帰率・戻る速度・崩壊耐性を可視化する

## 実装済み（MVP）

| 画面 | 内容 |
|------|------|
| 初回入力 | 目的（ダイエット/増量）・からだ・無理ない量・目標頻度 |
| 今日 | 今日やること／最低ライン／復帰可能性。空白日数でモード自動切替 |
| きろく | カレンダー（見返しやすい記録）＋月次集計＋最近の記録 |
| 継続力 | 崩壊耐性スコア・復帰率・戻る速度・戻ってこれた回数 |

データは端末の localStorage に保存。サーバー不要で動作します。

## 復帰ロジック（AIなし・通常ロジック）

最後に動いた日からの空白日数で「今日のモード」が決まります。

- 0〜1日: 通常モード
- 2〜3日: 軽めモード
- 4日〜: 復帰モード（最低ライン中心＋心理復帰メッセージ）

## AIの位置づけ（今後）

企画書の「AI緊急出動型」方針に沿って、AIは常駐させず以下の場面のみで使う設計：

- 初回プラン生成
- 挫折時の再設計
- 長期停滞からの再開支援

通知・タスク表示・記録・スケジュールは通常ロジックで処理し、API費を抑える。
